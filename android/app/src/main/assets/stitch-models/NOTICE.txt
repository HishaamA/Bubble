Models modified for Bubble by conversion to portable float32 ONNX, opset 17.
Learned weights are unchanged. Export uses fixed-capacity masked feature
selection and algebraically equivalent attention reshapes. LightGlue retains
all nine trained layers and uses exact upstream token-confidence early stopping
(depth confidence 0.95) in standard ONNX If branches. Point pruning is disabled.
Input dimensions and matcher feature counts are dynamic. Invalid detector
padding is removed before matching. No network access is used at inference.

Model fingerprints and CPU parity measurements are in model-report.json.
Reproduction: scripts/export-mobile-stitch-models.py at the project root.
