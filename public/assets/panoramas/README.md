# Bundled panorama fixtures

These images are development-only fixtures. They are bundled locally so the first
viewer proof has no runtime CDN dependency.

- `jordan-pond-demo.jpg`: `mpetroff/pannellum`, `examples/examplepano.jpg`
- `alma-demo.jpg`: `https://pannellum.org/images/alma.jpg`
- `sunday-dinner-demo.jpg`: AI-generated 2:1 concept panorama created for this
  prototype; it contains no real family members or source photography.

Replace these fixtures with explicit Bubble demo media before release. The
